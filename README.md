# Programming Guide for a Zombie Apocalypse: resources

Companion resources for the **Programming Guide for a Zombie Apocalypse**, a book that teaches programming with TypeScript from scratch, set during a zombie apocalypse. This is the extra material that goes with the book.

## Exercise solutions

The solutions to every exercise and challenge in the book, organized by block:

```text
solutions/
├── block01/              Chapters 1 to 6 and challenge 1
├── block02/              Chapters 7 to 12 and challenge 2
├── block03/              Chapters 13 to 18 and challenge 3
├── block04/              Chapters 19 to 21 and challenge 4
└── exercise-runner.ts    Solution runner
```

Each file is named `exerciseX.Y.ts` for exercise Y of chapter X, and `challengeX.ts` for the challenge of block X. Every solution stands on its own: you can read it and run it separately with Deno or with Node.js. The solutions for chapter 21 and challenge 4 include their tests in the same file.

See [`solutions/README.md`](solutions/README.md) for how to run them and check their types.

Try each exercise before you look at its solution. Your code doesn't have to match the one here: if it does what the exercise asks, it's valid.
